## Practical limits of verification

The NSIS installer was built and its output verified; installation/uninstallation on a fresh Windows account was not exercised. The build is unsigned. WebView2 is required; its installer bootstrapper is embedded, and acquiring a missing WebView2 runtime can require internet. After that prerequisite and installation, normal application use is offline.

Physical Windows suspend/resume, power loss, and changes to the OS clock were not induced. Deterministic Rust tests cover the chosen monotonic policy, large elapsed gaps, and restoration from durable checkpoints. On Windows, sleep while the process exists consumes exam time; time with the process closed does not. Checkpoints run every second, so abrupt termination may recover approximately one second of time (or more if storage was unavailable). Browser DPI scaling was exercised; OS display settings were not changed.

The sample is for rendering/import validation and the full-size fixture is synthetic software QA. They are explicitly not presented as genuine SPhO preparation examinations. Independently authored questions remain the author's responsibility for scientific correctness.
